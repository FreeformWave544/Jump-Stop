## About The Project
<br />
<p>
A simple Godot Platformer, with 3 or so levels, <b>BUT</b></br>
With a twist.</br>
<i>Your left/right mouse buttons FREEZE the player momentarily,</br>and stops ALL momentum, allowing you to cross distances, previously thought <b>impossible</b>!</i>
</p>

<!-- USAGE -->
## Usage
You can use it in web (via the [itch.io](https://freeformwave.itch.io/jumpstop)) OR download the desktop version, where the notepad will pop-out as a new window, so you can take notes on the fly, without leaving the program!
